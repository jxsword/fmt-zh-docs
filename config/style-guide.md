# fmt 中文文档翻译风格指南

## 核心原则

1. **准确性优先** - 术语翻译必须准确，遵循术语表
2. **专业性** - 使用专业技术文档语言，避免口语化
3. **一致性** - 同一术语全文统一译名
4. **可读性** - 符合中文技术文档阅读习惯

## 翻译规则

### 1. 代码与标识符保持原文

| 类型 | 处理方式 | 示例 |
|------|----------|------|
| 代码块 (```cpp ... ```) | 完全保持原文 | `fmt::print("{}", 42);` |
| 内联代码 (`fmt::format`) | 完全保持原文 | 使用 `fmt::format` 函数 |
| 函数名/类名/宏名 | 保持英文原名 | `fmt::formatter`, `FMT_STRING` |
| 头文件名 | 保持英文原名 | `<fmt/format.h>` |
| 变量名/参数名 | 保持英文原名 | `format_string`, `args` |
| 错误码/异常名 | 保持英文原名 | `format_error`, `system_error` |

### 2. 专业术语使用术语表

- 首次出现可括注原文：`格式字符串 (format string)`
- 后续统一使用中文译名
- 术语表未收录的术语，首次使用时在 PR 中讨论并加入术语表

### 3. 人称与语气

| 场景 | 推荐 | 避免 |
|------|------|------|
| 您/用户 | 您可以使用... | 你可以用... |
| 我们/作者 | 我们建议... | 我建议... |
| 一般陈述 | 此功能提供... | 这个功能挺好用的... |
| 指令 | 请参阅... | 你看一下... |

### 4. 标点符号

| 规则 | 示例 |
|------|------|
| 中文句子用中文标点 | 请参阅 `fmt::format` 文档。 |
| 夹杂代码时合理混用 | 函数 `fmt::print` 支持多种格式。 |
| 括号内纯英文可用英文标点 | 支持 C++20 (C++20) 编译时检查。 |
| 代码块内保持原文标点 | 代码块内不翻译标点 |

### 5. 数字与单位

| 规则 | 示例 |
|------|------|
| 阿拉伯数字 | 版本 10.2.1 |
| 数字与单位间加空格 | 约 20-30 倍、约 2 倍 |
| 版本号保持原格式 | v12.2.0 |

### 6. 格式规范

| 元素 | 处理方式 |
|------|----------|
| 标题层级 | 保持原文层级 (# ## ###) |
| 列表符号 | 保持原文符号 (- * 1.) |
| 表格 | 保持原文结构，仅翻译单元格文本 |
| 链接文本 | 翻译链接文本，URL 保持原文 |
| 图片 alt 文本 | 翻译 |
| 代码注释 | 翻译注释内容，代码保持原文 |

## 审校检查清单

- [ ] 所有术语表术语是否统一使用
- [ ] 代码块/内联代码/HTML/URL 是否保持原文
- [ ] 标题层级/列表/表格结构是否完整
- [ ] 中文标点是否规范
- [ ] 人称是否统一为"您"/"我们"
- [ ] 语气是否专业、简洁
- [ ] 无遗漏翻译段落
- [ ] 无 PROTECTED_* 占位符残留

## 争议处理

1. 术语翻译有歧义时，在 PR 讨论区决议
2. 更新术语表后，需同步更新所有已翻译文件
3. 重大分歧由维护者裁决
